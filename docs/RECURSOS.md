# Recursos

Interface e marca desenhadas para este projeto; sem fotografias, imagens geradas, logotipos de clientes ou dados corporativos. O roteiro inicial é sintético e identificado como exemplo.

Fontes servidas localmente pelos pacotes npm `@fontsource/dm-sans` e `@fontsource/newsreader`, versões fixadas no lockfile, distribuídas sob SIL Open Font License 1.1. As licenças estão também em `docs/licenses/`. Catálogos: https://fontsource.org/fonts/dm-sans e https://fontsource.org/fonts/newsreader. Não há pedido às APIs de fontes em runtime.

Vite e Playwright são ferramentas de desenvolvimento com suas licenças nos respectivos pacotes. README e lockfile permitem reconstruir dependências; node_modules não é parte do pacote de entrega.

Nenhum trecho de código de concorrentes foi reutilizado. A pesquisa usa declarações de capacidade dos READMEs públicos, com limites registrados em DECISAO.md.
